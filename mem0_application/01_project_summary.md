# Project Summary — SGNNET

SGNNET is a sparse O(N·K) graph neural network that replaces the fully-connected head of a frozen VGG16 feature extractor. The architecture routes activations on the unit hypersphere S^{D-1} via Fourier encoding and K iterations of gather-scatter, where each node only talks to K neighbours. The efficiency champion (step605, a K=1 knowledge-distilled student) hits **95.95% on Imagenette** while using **0.20M FLOPs (0.16% of VGG16 FC), 34,976 parameters (0.029%), and 12.7 µs B=32 wall-time on an RTX 5060 Ti — 5.26× faster than the dense FC head it replaces**. CIFAR-10 transfer is confirmed at 80.57% ±0.12pp over three seeds. The architecture Pareto-dominates VGG16 FC on accuracy, params, FLOPs, and wall-time; the only dimension it loses on is peak memory.

The collaboration with Claude Code is driven by a strict experimental protocol baked into the project's `CLAUDE.md`. A three-tier ladder (T0: 20 epochs / 50% data as a rejection filter; T1: 75 epochs / 50% data as a head-to-head comparison; T2: 150 epochs / 100% data for paper-bound claims) prevents wasted compute — empirically T0 predicts the T2 winner with ρ=0.80 over 46 calibration runs. Every causal claim is tagged **CONFIRMED**, **HYPOTHESIS**, or **STALE**. Compute is orchestrated across six training slots (mini_mps, mini_cpu, studio_mps, studio_cpu, 5060ti_cuda, 5060ti_cpu) through a single `launch_slot.sh` wrapper that enforces lock files, RAM gates, and tmux sessions. When SGNNET trailed the dense baseline on wall-time, the response was always "what closes the gap so SGNNET wins on efficiency?" — never to narrow scope.

Hundreds of experiments ran over several months. The collaboration produced a paper-ready manuscript, a multi-seed CIFAR-10 confirmation, a CUDA-optimized model variant (`model_resonant_cuda.py`) compiled with `torch.compile(mode="reduce-overhead")`, a sparse-op micro-benchmark suite, and an honest negative result on audio. Three formal meditations (`learnings/meditations/`) detected drift between experiment cadence and paper-writing progress and reset priorities back to the milestone. The collaboration's knowledge is triple-written: Graphiti temporal knowledge graph, dated `learnings/LEARNINGS_*.md` files, and concept wikis in `learnings/concepts/`. The same operating contract that produced these results is the one I'd bring to a backend role at Mem0.
