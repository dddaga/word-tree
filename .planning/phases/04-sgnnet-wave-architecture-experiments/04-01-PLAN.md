    Create `masked_normalize(x, eps_active=1e-6, eps_norm=1e-5)` function:
    - Input: `x` is `[batch, N, D]` tensor (real activations for Stage A, or Z_re/Z_im for phasor)
    - Compute magnitude per neuron: `mag = x.norm(dim=-1)` giving `[batch, N]`
    - Active mask: `active = (mag > eps_active)` giving `[batch, N]` bool
    - Compute mean and var ONLY over active neurons per batch element:
      ```python
      active_float = active.unsqueeze(-1).float()  # [batch, N, 1]
      count = active_float.sum(dim=1, keepdim=True).clamp(min=1)  # [batch, 1, 1]
      mean = (x * active_float).sum(dim=1, keepdim=True) / count  # [batch, 1, D]
      var = ((x - mean) ** 2 * active_float).sum(dim=1, keepdim=True) / count
      normalized = (x - mean) / (var.sqrt() + eps_norm)
      return normalized * active_float  # zero out inactive neurons
      ```
    - Per D-07: only neurons with |Z_j| > eps participate in mean/var

    **File 2: src/sgnnet/wave_routing.py** (~80 lines)

    Create `phasor_proximity_routing(Z_re, Z_im, W_pos, N_hidden, D, box_size, use_wphase=False, W_phase=None)`:
    - Input: `Z_re, Z_im` each `[batch, N_hidden, D]`, `W_pos` is `[N_hidden, D]`
    - Compute pairwise distances: `d_ij = ||W_pos_i - W_pos_j||` using `torch.cdist(W_pos, W_pos)` -> `[N_hidden, N_hidden]`
    - Compute r* via `personal_volume_radius(N_hidden, D, box_size)` (import from geometry.py)
    - Compute lambda: `lam = r_star / 2.0` (per D-08: wavelength = r*/2)
    - Gaussian strength: `strength = exp(-d^2 / r*^2) * (d < r*)` -> `[N_hidden, N_hidden]`
    - Zero diagonal: `strength.fill_diagonal_(0)`
    - Normalize per target: `strength = strength / (strength.sum(dim=0, keepdim=True) + 1e-8)` (sum over source dim)
    - Phase rotation: `phase_ij = 2 * pi * d_ij / lam` -> `[N_hidden, N_hidden]`
    - Compute phasor products (broadcast over batch):
      ```python
      cos_p = torch.cos(phase_ij)  # [N_hidden, N_hidden]
      sin_p = torch.sin(phase_ij)
      # Z_re: [batch, N_source, D], strength: [N_source, N_target]
      # For each target j: sum over sources i of strength_ij * (Z_re_i * cos - Z_im_i * sin)
      Z_prox_re = torch.einsum('ij,bjd->bid', strength * cos_p, Z_re) - torch.einsum('ij,bjd->bid', strength * sin_p, Z_im)
      Z_prox_im = torch.einsum('ij,bjd->bid', strength * sin_p, Z_re) + torch.einsum('ij,bjd->bid', strength * cos_p, Z_im)
      ```
    - If `use_wphase=True` and `W_phase is not None` (per D-10, Exp 2 only):
      ```python
      # W_phase: [N_hidden, D], per-neuron per-dimension learned phase
      cos_w = torch.cos(W_phase).unsqueeze(0)  # [1, N_hidden, D]
      sin_w = torch.sin(W_phase).unsqueeze(0)
      Z_out_re = Z_prox_re * cos_w - Z_prox_im * sin_w
      Z_out_im = Z_prox_re * sin_w + Z_prox_im * cos_w
      return Z_out_re, Z_out_im
      ```
    - Else: `return Z_prox_re, Z_prox_im`

    `__init__(self, N_hidden=256, N_out=10, D=4, N_in=25088, sparsity=0.90, K=3, box_size=1.0, use_proximity=False, use_wphase=False)`:

    `forward(self, x: Tensor[B, N_in]) -> Tensor[B, N_out]`:
    - Phase 1 (seeding): call `self._seed(x)`
    - Phase 2 (hidden iterations): call `self._iterate_hidden(Z_re, Z_im)` for K-1 steps

    - Return `Z_re, Z_im`

    `_iterate_hidden(self, Z_re, Z_im)`:
    - `W_hidden = self.W_pos[:self.N_hidden]`
    - For k in range(K-1):
      - Static path: `S_re = torch.einsum("bhd,hj->bjd", Z_re, C_hh_mask.float())`
      - `S_im = torch.einsum("bhd,hj->bjd", Z_im, C_hh_mask.float())`
      - If `self.use_proximity`:

        - `Z_re = masked_normalize(S_re + P_re)`
        - `Z_im = masked_normalize(S_im + P_im)`
      - Else (Stage A):
        - `Z_re = masked_normalize(S_re)`
        - `Z_im = torch.zeros_like(Z_re)` (keep imaginary zero in Stage A)
    - Return `Z_re, Z_im`

    - `S_re_out = torch.einsum("bhd,ho->bod", Z_re, C_ho_mask.float())`
    - If `self.use_proximity`:
      - Also compute proximity from hidden to output (using W_pos[N_hidden:] as targets)

    - Else:

    - Self-projection readout: `W_out_norm = F.normalize(self.W_pos[self.N_hidden:], dim=-1)`
    - `scores = (A_out * W_out_norm.unsqueeze(0)).sum(dim=-1)` -> `[batch, N_out]`
    - Return `scores`
