    ```python
    class Trainer:
        """Shared training loop for SGNNET_Wave experiments.

        Handles FP16 mixed precision on MPS, position clamping, gradient zeroing.
        Loss per TRAIN-01: total = KL + lambda_safety * safety_valve + lambda_lb * load_balance.
        """

        def __init__(self, model, train_loader, val_loader, lr_wpos=1e-3,
                     lr_wphase=None, lambda_safety=0.5, lambda_lb=0.01,
                     box_size=1.0, device="mps"):
            self.model = model.to(device)
            self.device = device
            self.box_size = box_size
            self.lambda_safety = lambda_safety
            self.lambda_lb = lambda_lb

            # Separate param groups: W_pos always, W_phase if present
            param_groups = [{"params": [model.W_pos], "lr": lr_wpos}]
            if model.W_phase is not None and lr_wphase is not None:
                param_groups.append({"params": [model.W_phase], "lr": lr_wphase})
            self.optimizer = torch.optim.Adam(param_groups)

            # FP16 setup (per D-09)
            self.use_grad_scaler = _check_grad_scaler_support()
            if self.use_grad_scaler:
                self.scaler = torch.amp.GradScaler(device)
            else:
                self.scaler = None

            self.train_loader = train_loader
            self.val_loader = val_loader
    ```

    **Helper `_check_grad_scaler_support()`:**
    ```python
    def _check_grad_scaler_support():
        """Return True if PyTorch >= 2.3 (MPS GradScaler safe)."""
        major, minor = torch.__version__.split(".")[:2]
        return int(major) > 2 or (int(major) == 2 and int(minor) >= 3)
    ```

    **Method `train_epoch(self) -> dict`:**
    - Import `safety_valve_loss` and `load_balance_loss` from `src.sgnnet.losses`
    - Iterate train_loader, for each batch (features, soft_labels, labels):
      - Move to device
      - `with torch.autocast(self.device, dtype=torch.float16):` (per D-09)
        - `scores = self.model(features)`
        - Compute KL loss: `task_loss = F.kl_div(F.log_softmax(scores, dim=-1), soft_labels, reduction='batchmean')` (per TRAIN-01)
        - `safety = safety_valve_loss(self.model.W_pos, self.box_size)`
        - `lb_loss = load_balance_loss(scores)` (load balance term from losses.py; if model has a gate output, pass that instead)
        - **Total loss per TRAIN-01:** `loss = task_loss + self.lambda_safety * safety + self.lambda_lb * lb_loss`
      - If scaler: `self.scaler.scale(loss).backward()`, `self.scaler.step(self.optimizer)`, `self.scaler.update()`
      - Else: `loss.backward()`, `self.optimizer.step()`
      - `self.optimizer.zero_grad()`
      - **Position clamping (TRAIN-03):** `with torch.no_grad(): self.model.W_pos.clamp_(0, self.box_size)`
      - Note: W_pos covers only hidden+output neurons (TRAIN-02 satisfied by model design -- no input neuron positions in model)
    - Return `{"train_loss": avg_loss, "task_loss": avg_task, "safety_loss": avg_safety, "lb_loss": avg_lb}`

    **Method `evaluate(self) -> dict`:**
    - Iterate val_loader in eval mode with `torch.no_grad()` and `torch.autocast`
    - Collect all scores and labels
    - Return dict with val_loss, scores array, labels array (for metrics computation by caller)

    **Method `train(self, n_epochs, log_fn=None) -> list[dict]`:**
    - For each epoch, call train_epoch() and evaluate()
    - Log via log_fn if provided
    - Return list of per-epoch metrics dicts
    - Check for NaN loss at each epoch: if `math.isnan(avg_loss)`, return early with `nan_detected=True`

    **Data loader note:** The trainer expects dataloaders that yield `(features, soft_labels, labels)` tuples. The caller creates these from the HDF5 store. Use `num_workers=0` (MPS constraint from STATE.md).

    ```python
    class GASearch:
        """Population-based GA hyperparameter search for SGNNET_Wave.

        Per D-11: population=20, generations=10, top_k=5,
                  partial_data_fraction=0.15, epochs_per_eval=15.
        Per D-03: fitness = -final_loss * (params_min / model_params)^0.2
        """

        def __init__(self, search_space, experiment_name, train_features, train_soft_labels,
                     train_labels, val_features, val_soft_labels, val_labels,
                     population=20, generations=10, top_k=5,
                     partial_fraction=0.15, epochs_per_eval=15,
                     n_in=25088, device="mps"):
            # n_in: input feature dimension, passed to SGNNET_Wave(N_in=n_in)
            # Default 25088 for production (VGG16 FC input), override for tests
            self.n_in = n_in
    ```

    **Search space dict format (per D-12):**
    ```python
    SEARCH_SPACE_AB = {
        "K": {"type": "discrete", "values": [1, 2, 3, 4]},
        "N_hidden": {"type": "discrete", "values": [64, 128, 256]},
        "lr_Wpos": {"type": "continuous_log", "low": 1e-5, "high": 1e-2},
        "lambda_safety": {"type": "continuous", "low": 0.0, "high": 1.0},
        "batch_size": {"type": "discrete", "values": [64, 128, 256]},
    }
    # D is fixed at 4 per D-02 -- not in search space

    SEARCH_SPACE_C = {**SEARCH_SPACE_AB,
        "lr_Wphase": {"type": "continuous_log", "low": 1e-5, "high": 1e-2},
    }
    ```

    **Method `_compute_params_min(self)`:**
    - Instantiate SGNNET_Wave with smallest config: N_hidden=64, K=1, D=4, N_in=self.n_in
    - Count trainable params: `sum(p.numel() for p in model.parameters())`
    - Store as `self.params_min`

    **Method `_random_individual(self) -> dict`:**
    - For each key in search_space:
      - discrete: random.choice(values)
      - continuous: random.uniform(low, high)
      - continuous_log: 10^random.uniform(log10(low), log10(high))

    **Method `_evaluate(self, config) -> float`:**
    - Build SGNNET_Wave with config["K"], config["N_hidden"], D=4, N_in=self.n_in, use_proximity/use_wphase from experiment_name
    - Create partial data loaders (random 15% subset of training data, per D-11)
    - Create Trainer with config["lr_Wpos"], lr_wphase=config.get("lr_Wphase")
    - Train for epochs_per_eval epochs
    - If NaN detected at any point: return -1e6 (per D-03 disqualification)
    - final_loss = mean of last 3 epoch losses
    - model_params = sum(p.numel() for p in model.parameters())
    - score = -final_loss * (self.params_min / model_params) ** 0.2
    - Return score

    **Method `_mutate(self, individual) -> dict`:**
    - For each param, with probability 0.3:
      - discrete: random resample from values
      - continuous: add Gaussian noise (sigma = 0.1 * (high - low))
      - continuous_log: multiply by 10^(Gaussian, sigma=0.3)
    - Clip to bounds

    **Method `_select(self, population_with_scores) -> list`:**
    - Sort by score descending
    - Keep top_k
    - Return them as parents for next generation

    **Method `run(self) -> dict`:**
    - Initialize population of `self.population` random individuals
    - For each generation:
      - Evaluate all individuals
      - Select top_k
      - Generate new population: top_k survive, rest are mutations of top_k
      - Log best score per generation
    - Return `{"best_config": best, "best_score": best_score, "history": per_gen_best}`
