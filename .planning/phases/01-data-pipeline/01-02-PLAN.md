   Class `VGGExtractor`:
   - `__init__(self, device: str = None)`:
     - If device is None, auto-detect: `"mps"` if `torch.backends.mps.is_available()` else `"cpu"`
     - Load VGG16 with pretrained ImageNet weights:
       ```python
       from torchvision.models import vgg16, VGG16_Weights
       self.model = vgg16(weights=VGG16_Weights.IMAGENET1K_V1)
       self.model.eval()
       self.model.to(self.device)
       ```
     - Freeze all parameters: `for p in self.model.parameters(): p.requires_grad_(False)`
     - Register forward hook on the feature extractor's output to capture activations:
       ```python
       self._features = None
       def _hook(module, input, output):
           # output shape: [batch, 512, 7, 7] -> flatten -> [batch, 25088]
           self._features = output.flatten(start_dim=1)
       self.model.avgpool.register_forward_hook(_hook)
       ```
       NOTE: In torchvision VGG16, the architecture is: model.features (conv layers) -> model.avgpool (AdaptiveAvgPool2d) -> model.classifier (FC layers). Hook on `model.avgpool` to capture the pooled output before the classifier flattens it.
     - Store `IMAGENET_INDICES` from dataset.py as a tensor for indexing:
       ```python
       from src.data.dataset import IMAGENET_INDICES
       self._imagenet_indices = torch.tensor(IMAGENET_INDICES, dtype=torch.long)
       ```

   - `extract_batch(self, images: Tensor) -> tuple[Tensor, Tensor]`:
     - images: [B, 3, 224, 224] on any device
     - Move images to self.device
     - Forward pass through full model (this triggers the hook AND produces logits):
       ```python
       with torch.no_grad():
           logits_1000 = self.model(images)  # [B, 1000]
       features = self._features  # [B, 25088] captured by hook
       ```
     - Select 10 Imagenette logits from 1000-class output (per D-03):
       ```python
       logits_10 = logits_1000[:, self._imagenet_indices]  # [B, 10]
       ```
     - Apply softmax at T=1 (per D-02 — raw softmax, NO temperature scaling):
       ```python
       soft_labels = torch.softmax(logits_10, dim=1)  # [B, 10]
       ```
     - Return (features.cpu(), soft_labels.cpu()) — move to CPU for storage

   - `extract_all(self, dataloader: DataLoader, desc: str = "Extracting") -> tuple[Tensor, Tensor, Tensor]`:
     - Iterate over entire dataloader with tqdm progress bar
     - For each batch: call extract_batch, collect features, soft_labels, and ground-truth labels
     - Concatenate all batches:
       ```python
       all_features = torch.cat(feature_list, dim=0)    # [N, 25088]
       all_soft_labels = torch.cat(soft_label_list, dim=0)  # [N, 10]
       all_labels = torch.cat(label_list, dim=0)          # [N]
       ```
     - Return (all_features, all_soft_labels, all_labels)

   - `@staticmethod`
     `write(path: str, train_data: tuple, val_data: tuple) -> None`:

     - val_data = (features, soft_labels, labels) from VGGExtractor.extract_all
     - Create HDF5 file with LOCKED schema (per D-05):
       ```python
       import h5py
       with h5py.File(path, "w") as f:
           # Train split
           f.create_dataset("train/features", data=train_features.numpy(),
                            dtype="float32", chunks=(1, 25088))
           f.create_dataset("train/soft_labels", data=train_soft_labels.numpy(),
                            dtype="float32", chunks=(1, 10))
           f.create_dataset("train/labels", data=train_labels.numpy(),

           # Val split
           f.create_dataset("val/features", data=val_features.numpy(),

                            dtype="float32", chunks=(1, 10))
           f.create_dataset("val/labels", data=val_labels.numpy(),
                            dtype="int64")
       ```

     - For val split: continue global index, h5_idx resets to 0
