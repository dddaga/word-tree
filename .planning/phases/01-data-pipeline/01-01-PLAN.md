   Key specifications:
   - Class `ImagenetteDataset(torch.utils.data.Dataset)`:
     - `__init__(self, root: str = "data/imagenette2-320", split: str = "train", transform=None)`:
       - `root` points to the imagenette directory
       - `split` is "train" or "val"
       - If `transform` is None, use DEFAULT_TRANSFORM (VGG16 standard preprocessing)
       - Loads images using `torchvision.datasets.ImageFolder` on `root/{split}/`
       - Maps Imagenette folder names to the 10 class indices (0-9)
     - `__len__()`: returns number of samples
     - `__getitem__(idx)`: returns (image_tensor, class_idx) where image_tensor is preprocessed

   - Constant `IMAGENETTE_CLASSES` — ordered list of 10 class names:
     ```python
     IMAGENETTE_CLASSES = [
         "tench", "English springer", "cassette player", "chain saw",
         "church", "French horn", "garbage truck", "gas pump",
         "golf ball", "parachute"
     ]
     ```

   - Constant `IMAGENET_INDICES` — mapping from Imagenette class position (0-9) to ImageNet 1000-class index:
     ```python
     IMAGENET_INDICES = [0, 217, 482, 491, 497, 566, 569, 571, 574, 701]
     ```

   - Constant `DEFAULT_TRANSFORM`:
     ```python
     DEFAULT_TRANSFORM = transforms.Compose([
         transforms.Resize(256),
         transforms.CenterCrop(224),
         transforms.ToTensor(),
         transforms.Normalize(
             mean=[0.485, 0.456, 0.406],
             std=[0.229, 0.224, 0.225]
         ),
     ])
     ```

   - Constant `IMAGENETTE_FOLDER_TO_IDX` mapping folder names (e.g., "n01440764") to local class indices (0-9). The Imagenette folder names are:
     ```python
     IMAGENETTE_FOLDER_TO_IDX = {
         "n01440764": 0,   # tench
         "n02102040": 1,   # English springer
         "n02979186": 2,   # cassette player
         "n03000684": 3,   # chain saw
         "n03028079": 4,   # church
         "n03394916": 5,   # French horn
         "n03417042": 6,   # garbage truck
         "n03425413": 7,   # gas pump
         "n03445777": 8,   # golf ball
         "n03888257": 9,   # parachute
     }
     ```

   - Helper function `get_dataloader(split: str, batch_size: int = 256, num_workers: int = 4) -> DataLoader`:
     Creates and returns a DataLoader wrapping ImagenetteDataset for the given split.

   - The class must remap ImageFolder's arbitrary class_to_idx to our canonical 0-9 ordering using IMAGENETTE_FOLDER_TO_IDX. ImageFolder assigns indices alphabetically which may NOT match our ordering.
