    ```python
    class SGNNET(nn.Module):
        def __init__(self, N_hidden=256, N_out=10, D=4, N_in=25088,
                     sparsity=0.90, K=3, box_size=1.0):
    ```

    **Constructor (__init__):**
    - Store all hyperparams as instance attributes
    - `self.W = nn.Parameter(torch.rand(N_hidden + N_out, D) * box_size)` — per D-03, only hidden+output
    - Precompute and register spatial encoding buffer: `self.register_buffer('spatial_coords', compute_spatial_encoding(N_in))`
    - Create three sparse C matrices per D-05:
      - `C_input`: shape [N_in, N_hidden]. Generate random mask with `(torch.rand(...) < (1 - sparsity))`. Then guarantee >= 1 connection per input row: for each row with all zeros, randomly set one entry to 1. Register mask as buffer, values as nn.Parameter initialized with `torch.randn(...) * mask * 0.01`.
      - `C_hh`: shape [N_hidden, N_hidden], same pattern. Zero diagonal. Register mask as buffer, values as nn.Parameter.
      - `C_ho`: shape [N_hidden, N_out], same pattern. Register mask as buffer, values as nn.Parameter.
    - `self.norm = nn.LayerNorm(D)` — per D-11, affine=True default
    - `self._last_gate = None` — initialize to None; updated during forward pass when K > 1

    **Forward (forward):**
    Per D-06, three-phase structure:

    Phase 1 — Seeding (once):
    ```python
    # x: [batch, N_in] — flat 25088-dim feature vector
    B = x.shape[0]
    # Build A_input: [batch, N_in, D=4]
    spatial = self.spatial_coords.unsqueeze(0).expand(B, -1, -1)  # [B, N_in, 3]
    A_input = torch.cat([x.unsqueeze(-1), spatial], dim=-1)       # [B, N_in, 4]

    C_in = self.C_input_values * self.C_input_mask  # [N_in, N_hidden]
    A_hidden = F.relu(self.norm(torch.einsum('bid,ih->bhd', A_input, C_in)))  # [B, N_hidden, D]
    ```

    Phase 2 — Hidden iterations (K-1 steps):
    ```python
    W_hidden = self.W[:self.N_hidden]  # [N_hidden, D]
    C_hh = self.C_hh_values * self.C_hh_mask  # [N_hidden, N_hidden]
    self._last_gate = None  # Reset before loop; stays None if K==1 (loop runs 0 times)
    for k in range(self.K - 1):
        static = torch.einsum('bhd,hj->bjd', A_hidden, C_hh)  # [B, N_hidden, D]
        dyn, gate = dynamic_connectivity_hh(A_hidden, W_hidden, self.N_hidden, self.D, self.box_size)
        self._last_gate = gate  # Overwritten each iteration; final value is from last iteration
        A_hidden = F.relu(self.norm(static + dyn))
    ```

    IMPORTANT: `self._last_gate` is assigned inside the loop body. When K=1, the loop
    `range(self.K - 1)` runs 0 times, so `self._last_gate` remains None. This is correct
    behavior — Plan 03-03's `total_loss` checks `gate is not None` before computing
    load balance loss.

    Phase 3 — Output injection (step K):
    ```python
    W_out = self.W[self.N_hidden:]  # [N_out, D]
    C_ho = self.C_ho_values * self.C_ho_mask  # [N_hidden, N_out]
    static_out = torch.einsum('bhd,ho->bod', A_hidden, C_ho)  # [B, N_out, D]
    dyn_out = dynamic_connectivity_ho(A_hidden, W_out, self.N_hidden, self.D, self.box_size)
    A_out = F.relu(static_out + dyn_out)  # NO norm at final step per D-11
    ```

    Readout — per D-06 and ARCH-03:
    ```python
    W_norm = F.normalize(W_out, dim=-1)  # [N_out, D]
    scores = (A_out * W_norm.unsqueeze(0)).sum(dim=-1)  # [B, N_out]
    scores = scores + 1e-4  # epsilon safety net per D-07
    return scores
    ```
