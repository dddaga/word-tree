    Create `src/sgnnet/losses.py` with three functions:

    1. `safety_valve_loss(W, box_size=1.0, N=None, D=None)`:
       Per report Section 7.2 — dead-zone Coulomb repulsion:
       ```python
       r_star = personal_volume_radius(N, D, box_size)
       r_repel = r_star / 2.0

       # Mutual repulsion: 1/d - 1/r_repel, only when d < r_repel
       dists = torch.cdist(W, W)  # [N_total, N_total]
       mask = ~torch.eye(W.shape[0], dtype=torch.bool, device=W.device)
       d_pairs = dists[mask].clamp(min=1e-8)
       mutual = F.relu(1.0 / d_pairs - 1.0 / r_repel).mean()

       # Boundary repulsion: each wall face independently
       dist_lower = W.clamp(min=1e-8)
       dist_upper = (box_size - W).clamp(min=1e-8)
       d_wall = torch.minimum(dist_lower, dist_upper)
       boundary = F.relu(1.0 / d_wall - 1.0 / r_repel).mean()

       return mutual + boundary
       ```
       N and D are for the hidden+output neurons only (per D-03, input neurons excluded from safety valve). If N is None, infer from W.shape[0]. If D is None, infer from W.shape[1].

    2. `load_balance_loss(selection_counts)`:
       Per D-08 and report Section 7.3:
       ```python
       freq = selection_counts.float() / (selection_counts.sum() + 1e-8)
       return freq.var()
       ```
       selection_counts: [N_hidden] — sum of gate over batch dim from model._last_gate.

    3. `total_loss(scores, targets, W, gate=None, box_size=1.0, N=None, D=None, lambda_safety=0.5, lambda_lb=0.01)`:
       ```python
       task = F.kl_div(F.log_softmax(scores, dim=-1), targets, reduction='batchmean')
       safety = safety_valve_loss(W, box_size, N, D)
       lb = load_balance_loss(gate.sum(dim=(0, 1))) if gate is not None else torch.tensor(0.0)
       return task + lambda_safety * safety + lambda_lb * lb
       ```
       Note: task loss is KL divergence for distillation (soft label targets from HDF5 store), not MSE. targets are the soft probability vectors from VGG16.

       ```python
       model = SGNNET(N_hidden=16, N_out=10, D=4, K=2)

       x = torch.randn(4, 25088)
       target = F.softmax(torch.randn(4, 10), dim=-1)

       W_before = model.W.data.clone()
       for step in range(3):
           scores = model(x)
           gate = model._last_gate

           loss.backward()
           optimizer.step()
       W_after = model.W.data.clone()

       ```
