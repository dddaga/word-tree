    ```python
    def compute_spatial_encoding(n_in: int = 25088, h: int = 7, w: int = 7, c: int = 512) -> torch.Tensor:
    ```
    Per D-02, for flat index k in [0, n_in):
    - channel = k // (h * w)
    - row = (k % (h * w)) // w
    - col = (k % (h * w)) % w
    - h_norm = row / (h - 1)  # 0.0..1.0
    - w_norm = col / (w - 1)  # 0.0..1.0
    - channel_norm = channel / (c - 1)  # 0.0..1.0
    Returns: Tensor[n_in, 3] of [h_norm, w_norm, channel_norm].

    Create `src/sgnnet/geometry.py` with three functions:

    1. `personal_volume_radius(N: int, D: int, box_size: float = 1.0) -> float`:
       r* = (box_size / 2) / N^(1/D)

    2. `dynamic_connectivity_hh(A_hidden, W_hidden, N_hidden, D, box_size=1.0)`:
       Per D-08 and D-10: operates on hidden neurons only.
       - A_hidden: [batch, N_hidden, D]
       - W_hidden: [N_hidden, D]
       - Compute r* = personal_volume_radius(N_hidden, D, box_size)
       - dists = torch.cdist(A_hidden, W_hidden.unsqueeze(0).expand(batch,-1,-1))  # [batch, N_hidden, N_hidden]
       - strength = exp(-dists^2 / (r*^2 + 1e-8))
       - gate = (dists < r*).float()
       - strength = strength * gate
       - Zero diagonal: strength[:, i, i] = 0 for all i (no self-connections)
       - Normalize per column: strength / (strength.sum(dim=1, keepdim=True) + 1e-8)
       - contribution = einsum('bij,bjd->bid', strength, A_hidden)  # [batch, N_hidden, D]
       - Return (contribution, gate)

    3. `dynamic_connectivity_ho(A_hidden, W_out, N_hidden, D, box_size=1.0)`:
       Per D-07 and D-10: hidden activations routing to output positions.
       - A_hidden: [batch, N_hidden, D]
       - W_out: [N_out, D]
       - dists = cdist(A_hidden, W_out.unsqueeze(0).expand(batch,-1,-1))  # [batch, N_hidden, N_out]
       - strength = exp(-dists^2 / (r*^2 + 1e-8)) * (dists < r*).float()
       - Normalize per output neuron (dim=1): strength / (strength.sum(dim=1, keepdim=True) + 1e-8)
       - contribution = einsum('bio,bid->bod', strength, A_hidden)  # [batch, N_out, D]
       - Return contribution (no gate needed per D-08)

    IMPORTANT: Use batched cdist (no per-sample loop). A_hidden is [batch, N_h, D], W is [N_h, D] — expand W to [batch, N_h, D] for cdist.

    File size target: encoding.py ~40 lines, geometry.py ~100 lines.
