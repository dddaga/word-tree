    **Step 3: Create src/utils/metrics.py** (per D-04, D-05, D-06)
    Three functions:

    `compute_all_metrics(scores: np.ndarray, labels: np.ndarray, class_names: list[str]) -> dict`:
    - `scores` is softmax probabilities [N, C] float32 (per D-04: caller applies softmax)
    - `preds = np.argmax(scores, axis=1)` for top-1
    - `top1_acc = float(np.mean(preds == labels))`
    - Per-class precision/recall/F1 via `sklearn.metrics.precision_recall_fscore_support(labels, preds, average=None, labels=list(range(num_classes)), zero_division=0)` (per D-06)
    - Per-class accuracy: for each class i, `mask = labels == i; acc = float(np.mean(preds[mask] == i)) if mask.sum() > 0 else 0.0`
    - mAP via one-vs-rest: `labels_onehot = np.eye(num_classes, dtype=np.float32)[labels]`, then for each class i call `sklearn.metrics.average_precision_score(labels_onehot[:, i], scores[:, i])`, average across classes (per D-06)
    - Return plain dict (per D-05): `{"top1_accuracy": float, "mAP": float, "per_class": {name: {"accuracy": float, "precision": float, "recall": float, "f1": float, "AP": float}}}`

    `count_params(model: torch.nn.Module) -> int`:
    - `return sum(p.numel() for p in model.classifier.parameters())`
    - Counts FC layers ONLY (model.classifier), not full VGG16

    `count_flops(model: torch.nn.Module, input_shape: tuple[int, ...]) -> int` (per D-01, D-02):
    - `from thop import profile`
    - `dummy = torch.randn(*input_shape)`
    - `macs, _ = profile(model.classifier, inputs=(dummy,), verbose=False)`
    - `return int(macs)`
    - Profiles model.classifier ONLY (FC layers), NOT full VGG16
    - Returns MACs (not 2x FLOPs) — document in docstring
