1. Implement `src/sgnnet/model_proximity_wave.py`:
   - Class SGNNET_ProximityWave(nn.Module)
   - Constructor args: N_hidden, D, K_in, K_local, K_random, N_in=25088, N_out=10, reconnect_every=10
   - `build_knn_conn(W_pos, K_local, K_random)`: compute pairwise distances on W_pos, take top-K_local nearest neighbors per neuron, add K_random random shortcuts. Return sparse edge list (src_idx, dst_idx) of shape [N_hidden * (K_local + K_random), 2]. Overlap is natural from geometry (no forced groups).
   - `sparse_phasor_route(Z_re, Z_im, conn_hh, W_pos, r_star)`: for each edge (i,j) in conn_hh, compute d_ij = ||W_pos[i] - W_pos[j]||, strength = exp(-d^2 / r_star^2), phase = 2*pi*d_ij / (r_star/2). Apply phasor rotation and accumulate at destination. O(N * K * B * D) per call.
   - `tick_epoch(epoch)`: if epoch % reconnect_every == 0, rebuild conn_hh from current W_pos via build_knn_conn. Log topology change count.
   - Forward pass: seed from conn_in (same as SmallWorld random K_in=50), then K_iter steps of sparse_phasor_route, then magnitude readout + self-projection.
   - conn_in construction: same random sparse gather as SmallWorld (K_in=50 from N_in=25088)
   - Register W_pos as nn.Parameter, conn_hh as buffer (rebuilt periodically)
